¿Qué es esto?

Para quien llegó sin saber de tecnología.

Un servidor es un computador que está siempre prendido para dar un servicio a otros: mostrar páginas web, guardar archivos compartidos o decidir quién puede entrar a un sistema. Casi todo lo que usas en internet funciona gracias a servidores.

Proyecto: servidor para NovaTech

Taller práctico de Linux Server, en 7 fases.

  1. Servidor: Ubuntu con nombre enterprise07.
  2. Conectividad: revisión de red y pruebas de ping.
  3. Firewall: UFW con solo los puertos necesarios.
  4. SSH: acceso remoto desde Windows.
  5. Samba: recurso compartido Public.
  6. Apache: publicación web.
  7. OpenLDAP: dominio empresa.local y usuarios.
