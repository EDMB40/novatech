Sobre el proyecto

Este servidor Ubuntu fue configurado como parte del taller práctico de Linux Server de Fundamentos de Sistemas Operativos, en la Corporación Universitaria Americana. El objetivo fue simular la infraestructura básica de una empresa: red, firewall, acceso remoto, archivos compartidos, web y directorio de usuarios.
